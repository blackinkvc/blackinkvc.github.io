# 科幻科技实现蓝图 · 项目蓝图

> 以严肃科学、第一性原理与超级工程师工作方法，研究科幻作品中的科技如何实现（或为何不能），
> 并建立可检索、可可视化的研发知识库。

## 1. 项目目标
- 建立科幻科技的**五级可行性分类体系**
- 为每项技术提供**第一性原理拆解**（原理 → 物理基础 → 工程可行性 → 关键瓶颈 → 研发路径）
- 提供**世界观简介系统**，标注各宇宙的“物理法则设定”与现实物理的偏离度
- 提供**可视化科技树**，呈现技术依赖与可行性层级
- 提供可复用的**研发设计 SOP**（12 阶段）

## 2. 五级可行性分类体系

### 已实现（Implemented）
- 色标：![c](#2e9e5b)
- 定义：已有可工作原型、商业化产品或经同行验证的实验室系统。工程问题已解决或接近解决，重点转向成本、规模与可靠性。
- 原则：现实物理 + 成熟工程。可直接作为其他技术的基石。
- 典型路线：量产化 / 降本 / 集成 / 下一代迭代

### 目前技术可实现（Technically Feasible Now）
- 色标：![c](#3a8fd0)
- 定义：物理原理清晰、关键材料/工艺已出现，暂无不可逾越的根本性障碍。受限于成本、规模、可靠性或系统集成，但 10–30 年内有望工程化。
- 原则：现实物理已支撑原理验证（PoC），缺工程化与规模化。
- 典型路线：原理验证 → 工程样机 → 系统集成 → 规模验证

### 未来可能实现（Possibly Implementable）
- 色标：![c](#c7902a)
- 定义：不违反已知物理定律，但依赖尚未存在或极不成熟的技术突破（如材料科学、能源密度、算力）。需多项前置技术协同成熟，时间尺度 50–200+ 年。
- 原则：不违背物理，但依赖尚未出现的使能技术（enabler）。
- 典型路线：前置使能技术突破 → 原理重估 → 长周期工程化

### 未来较难实现（Difficult to Implement）
- 色标：![c](#c9542f)
- 定义：理论上未完全证伪，但与当前物理框架存在张力，或需要逼近理论极限的能量/精度/尺度。实现概率低，需范式级突破或新物理。
- 原则：与现有物理有张力或需逼近理论极限；需新物理或范式转移。
- 典型路线：新物理探索 → 极限工况验证 → 极高成本原型

### 仅限该世界观（Worldview-Only）
- 色标：![c](#8a5cd0)
- 定义：依赖该虚构宇宙特有的“设定法则”（如原力、灵能、魔法、时空重置），这些法则在现实物理中无对应机制。作为创作素材与思想实验保留，并标注其“破壁”所需替换的物理公设。
- 原则：依赖虚构设定法则；若要现实化需显式替换基础物理公设。
- 典型路线：设定解构 → 公设替换 → 判定能否进入其他分级

- 物理法则设定：
  - 相对论与热力学严格成立，无超光速（除非曲速这类依赖时空度规的方案）

### 太空歌剧（Space Opera）
- 现实偏离度：中
- 简介：宏大叙事优先，允许超光速旅行与星际文明，但对个体科技常作一定解释。代表：《星际迷航》《星球大战》（部分）。
- 物理法则设定：
  - 允许超光速引擎（曲速/跃迁）作为运力前提
  - 允许能量护盾、相位武器等但常含糊其物理
  - 文明尺度极大，存在古老高级文明
  - 个体生命形态多样（有机/合成/能量态）
- 典型科技：曲速引擎（阿库别瑞度规）、冬眠 / 人体冷冻、超光速通信、反重力 / 引力屏蔽、分子级物质重组（复制机）、物质量子隐形传态、体积全息显示、奇异物质/负能量密度、可穿越虫洞、宏观瞬时传送、能量护盾(硬防护场)、光剑(等离子约束)

### 太空奇幻（Space Fantasy / Mythic Sci-Fi）
- 现实偏离度：高
- 简介：以魔法/灵能代替或补充科技，常含命定、原力、灵魂等概念。代表：《星球大战》（原力侧）、《沙丘》（部分）。
- 物理法则设定：
  - 存在可感知、可利用的“宇宙能量场”（原力/灵能）
  - 个体可凭精神影响物质与世界
  - 命运、预言等超自然叙事成立
  - 科技与神秘学混融
- 典型科技：意识上传、时间旅行（回到过去）、原力 / 灵能、星际心灵感应、时空重置 / 宇宙重启、魔法系统（规则化法术）、平行宇宙航行、额外维度利用、永动机(违反热力学)、光剑(等离子约束)、脱离躯体的独立意识、念力/念动力、预言/命运、任意维度旅行、许愿神器、神话式不死不灭、元素/自然操控、灵魂转移/夺舍、虚空造物、局部时间停止

### 蒸汽朋克（Steampunk）
- 现实偏离度：中
- 简介：以维多利亚机械美学为底，用发条、蒸汽、早期电学替代电子与计算机，强调可见的齿轮与管道。代表：《差分机》《蒸汽男孩》。
- 物理法则设定：
  - 允许成熟的机械/蒸汽/电磁技术，但无现代半导体与数字计算
  - 信息与控制在机械/气动层面实现（分析机式）
  - 能量仍受热力学与材料限制
  - 常与架空历史与阶级叙事结合
- 典型科技：动力外骨骼、电磁发射/轨道炮、增材制造（3D打印）

### 生物朋克（Biopunk）
- 现实偏离度：低-中
- 简介：以生物科技而非电子为核心，关注基因改造、生物黑客、身体可被任意改写。代表：《傀儡师》《GATTACA》《变蝇人》。
- 物理法则设定：
  - 现实生物物理基本成立
  - 强调基因/合成生物/生物制造的可及与滥用
  - 身体是‘可编辑材料’
  - 伦理焦点在生命改造的边界
- 典型科技：合成生物学、转基因/基因农业、培养肉/细胞农业、基因编辑（CRISPR-Cas）、生物打印器官、衰老逆转

### 末日废土（Post-Apocalypse）
- 现实偏离度：低
- 简介：文明崩溃后的重建/求生叙事，技术多为拼凑、低效但可用的废墟科技。代表：《疯狂的麦克斯》《最后生还者》《辐射》。
- 物理法则设定：
  - 现实物理成立，重点是基础设施缺失
  - 技术以‘ salvage(拾荒复用)’为主
  - 能源与制造能力碎片化
  - 社会组织回归小共同体
- 典型科技：小型模块化反应堆(SMR)、增材制造（3D打印）、平流层太阳辐射管理、直接空气捕集(DAC)、自主货运(海/陆/空)

### 模拟假说（Simulation Hypothesis）
- 现实偏离度：中-高
- 简介：设定‘现实是更高文明运行的模拟’，由此引出可‘修改参数’的元层技术。代表：《黑客帝国》《瑞克和莫蒂》(元层)。
- 物理法则设定：
  - 表层遵循现实物理（被模拟）
  - 存在可干预的‘模拟参数/控制层’
  - 意识可能为计算实体
  - 突破靠访问元层而非改物理
- 典型科技：通用人工智能(AGI)、全球脑/集体智能、城市数字孪生、大模型智能体(窄强AI)、意识上传

### 巨型结构文明（Megastructure Civilization）
- 现实偏离度：低-中
- 简介：以行星/恒星尺度的建造为常态的文明阶段（卡尔达肖夫进阶），强调工程规模的跃迁。代表： Banks《文化》环world、Niven 环形世界。
- 物理法则设定：
  - 现实物理成立，尺度极大
  - 能源以恒星级采集为前提
  - 材料/自复制/自动化建造是关键
  - 文明能量等级决定可行工程
- 典型科技：戴森球 / 戴森云、轨道太阳能电站、宇宙尺度工程、太空电梯、火星永久殖民地

### 太空西部（Space Western）
- 现实偏离度：低
- 简介：把西部拓荒叙事搬上星球边境，技术实用、法律松弛、个人英雄主义。代表：《萤火虫》《星际牛仔》《苍穹浩瀚》(部分)。
- 物理法则设定：
  - 现实物理基本成立
  - 前沿拓荒：低成本航天与就地资源
  - 治理稀疏，私力救济常见
  - 技术是‘够用即可’的务实主义
- 典型科技：可重复使用运载火箭、小行星采矿、火星永久殖民地、自主货运(海/陆/空)、低轨卫星互联网

## 4. 技术条目总览（102 项）

### 已实现（21 项）
- **可重复使用运载火箭**（Reusable Launch Vehicle）— TRL 9/9：通过垂直回收（动力软着陆）与快速翻新，把一次性消耗品变成可复飞资产，摊薄单次入轨成本。
- **语音智能助手**（Voice Assistant）— TRL 9/9：语音识别(ASR) + 自然语言理解(NLU) + 对话管理 + 语音合成(TTS) + 工具调用，形成可对话的软件代理。
- **基因编辑（CRISPR-Cas）**（Gene Editing）— TRL 8/9：用向导 RNA 定位特定 DNA 序列，由 Cas 蛋白切割并触发细胞修复，实现定点敲除/插入/替换。
- **虚拟现实 / 增强现实**（VR / AR）— TRL 8/9：用头显+惯性/视觉追踪构造沉浸式 3D 显示（VR）或将数字信息叠加现实（AR）。
- **自主无人机/无人系统**（Autonomous Drones）— TRL 9/9：多旋翼/固定翼平台 + 感知(SLAM) + 自主导航 + 任务规划，实现无人化作业。
- **增材制造（3D打印）**（Additive Manufacturing）— TRL 9/9：逐层堆积材料（塑料/金属/陶瓷）按数字模型成型，省去模具与减材浪费。
- **自动驾驶**（Self-Driving）— TRL 8/9：多传感器(激光雷达/视觉)感知 + 预测 + 规划 + 控制，实现无需人类干预的驾驶。
- **可穿戴健康监测**（Wearable Health Monitoring）— TRL 9/9：体表传感器持续采集心率/血氧/ECG/运动，经算法给出健康预警。
- **机器人辅助手术**（Robotic Surgery）— TRL 9/9：主刀医生通过机械臂远程精细操作，消除震颤、放大视野、微创。
- **锂离子/电化学储能**（Li-ion & Electrochemical Storage）— TRL 9/9：锂离子在正负极间往复嵌入脱嵌，实现高能量密度可充电储能。
- **智能移动计算**（Smart Mobile Computing）— TRL 9/9：把通信、传感、计算、显示集成于掌上设备，接入全球网络。
- **计算机视觉/人脸识别**（Computer Vision / Face Recognition）— TRL 9/9：用卷积/Transformer从图像提取特征并识别物体、人脸、行为。
- **动力外骨骼**（Powered Exoskeleton）— TRL 7/9：穿戴式机械结构+执行器放大或辅助人体力量与耐力。
- **转基因/基因农业**（GMO & Gene Agriculture）— TRL 9/9：通过转基因/基因编辑改造作物性状（抗虫、高产、营养强化）。
- **实时机器翻译**（Real-time Machine Translation）— TRL 9/9：端到端神经网络将一种语言实时转为另一种，含语音与文字。

- **定向能(致盲/低功率激光)**（Low-power Directed Energy）— TRL 8/9：用定向光束传递能量，实现致盲、干扰或低功率毁伤。
- **低轨卫星互联网**（LEO Satellite Internet）— TRL 9/9：大规模低轨星座构成天基网络，提供全球低延迟互联网。

### 目前技术可实现（25 项）
- **可控核聚变发电**（Controlled Nuclear Fusion）— TRL 5/9：将轻核（氘氚）加热到等离子态并约束，使聚变释放能量超过加热与损耗（Q>1）。
- **脑机接口**（Brain-Computer Interface）— TRL 6/9：在神经组织与机器间建立信号通路：采集神经电活动(ECoG/微电极)并解码意图，或电刺激写入感知/运动。
- **量子计算机**（Quantum Computer）— TRL 4/9：利用叠加与纠缠做并行态空间演化，对特定问题（因数分解、量子模拟、优化）指数加速。
- **太空电梯**（Space Elevator）— TRL 3/9：用同步轨道缆绳连接地表与配重，依靠 climber 沿缆爬升，把入轨能耗从火箭化学能降到电力。
- **人工光合作用 / 合成燃料**（Artificial Photosynthesis）— TRL 4/9：用催化剂在光照下把水/CO₂ 直接转成燃料(甲醇/氢/碳氢)或化学品，模拟并超越自然光合。
- **固态电池**（Solid-state Battery）— TRL 6/9：以固态电解质替代液态，提升能量密度与安全性。
- **大模型智能体(窄强AI)**（LLM Agents (Narrow Strong AI)）— TRL 6/9：以大模型为中枢，配记忆、工具调用、规划，完成多步任务。
- **电动垂直起降(eVTOL)**（eVTOL）— TRL 7/9：多旋翼/倾转构型实现城市空中通勤，电动低噪。
- **直接空气捕集(DAC)**（Direct Air Capture）— TRL 6/9：用化学吸附从大气直接捕集CO₂，封存或利用。
- **小型模块化反应堆(SMR)**（Small Modular Reactor）— TRL 7/9：工厂预制小型核裂变堆，模块化部署，被动安全。
- **量子密钥分发(QKD)**（Quantum Key Distribution）— TRL 7/9：利用量子不可克隆/测不准，使窃听必被察觉地分发密钥。
- **城市数字孪生**（Urban Digital Twin）— TRL 6/9：用实时数据构建城市的动态虚拟镜像，用于仿真与调度。
- **合成生物学**（Synthetic Biology）— TRL 6/9：像搭电路一样设计与组装生物部件，让活体生产燃料/材料/药物。
- **电磁发射/轨道炮**（Electromagnetic Launch / Railgun）— TRL 7/9：用强电流在导轨间产生洛伦兹力，将载荷加速到极高速度。
- **高密度非侵入脑机**（High-density Non-invasive BCI）— TRL 6/9：以高密度头皮传感+AI解码实现无需开颅的脑信号交互。
- **无人化智能制造**（Lights-out Manufacturing）— TRL 8/9：由机器人+AI调度实现无需人工值守的全自动生产。
- **微小卫星/快速星座**（Smallsat / Rapid Constellation）— TRL 9/9：以低成本微小卫星批量组网，提供遥感/通讯/科学载荷。
- **培养肉/细胞农业**（Cultured Meat / Cellular Agriculture）— TRL 6/9：从动物细胞在生物反应器中培养肌肉组织，替代屠宰养殖。
- **钙钛矿/叠层光伏**（Perovskite / Tandem PV）— TRL 6/9：用钙钛矿吸光层(或与硅叠层)提升光电转换效率、降成本。
- **无线能量传输**（Wireless Power Transfer）— TRL 6/9：以电磁感应为近场、微波/激光为远场，实现无缆供电。
- **自主货运(海/陆/空)**（Autonomous Freight）— TRL 8/9：在限定场景(港口、干线、航道)实现无人的货物自主运输。
- **生物打印器官**（Bioprinted Organs）— TRL 5/9：用细胞‘墨水’按三维结构打印组织与器官移植物。
- **平流层太阳辐射管理**（Stratospheric SRM）— TRL 4/9：向平流层注入气溶胶反射部分阳光，临时降低全球气温。
- **AI 药物发现**（AI Drug Discovery）— TRL 6/9：用AI预测蛋白结构、生成分子并设计试验，加速新药研发。
- **量子互联网**（Quantum Internet）— TRL 5/9：以纠缠分发与量子中继连接节点，实现不可克隆的量子态传输与增强安全。
