实时数据接口

三个接口均在浏览器端直接请求，无自建后端、无第三方代理。请求失败时优先读取 localStorage 缓存并明确标注“缓存”，无缓存则显示“不可用”，不会用示例数据冒充实时数据。

USGS 地震目录U.S. Geological Survey

earthquake.usgs.gov/earthquakes/feed/v1.0
公有领域 无需 API Key GeoJSON
许可类型
美国联邦政府作品，依 17 U.S.C. §105 不受版权保护；USGS 数据政策允许自由使用与再分发，不要求书面许可。
法律要求
USGS 不保证数据的完整性、准确性或时效性；使用时不得暗示 USGS 对本项目背书。官方建议注明数据来源与获取时间。
本项目加工
  • 按时间窗选择 all_hour / all_day / all_week / all_month 四个目录；
  • 仅保留 type=earthquake 且有震级的事件，剔除爆炸、采石等非天然事件；
  • 坐标、震级、深度、发震时刻原样使用，不做平滑或插值；
  • 震级映射为颜色与波纹半径（severity = mag / 8 × 100，仅用于视觉分级）；
  • 英文地名做中文对照翻译，未收录地名保留原文；
  • 渲染上限 4200 条，超出时按震级降序截断并在数据源弹窗中注明。
再分发注意
可直接再分发。建议保留 properties.url 原始事件链接与获取时间；若二次加工，应说明“基于 USGS 数据加工”，不得删除免责说明。

NASA EONET v3Earth Observatory Natural Event Tracker

eonet.gsfc.nasa.gov/api/v3
NASA 开放数据 无需 API Key 可自由使用
许可类型
NASA 开放数据，通常不受版权保护，可自由使用；须遵守 NASA 媒体使用指南，不得暗示 NASA 背书。
法律要求
EONET 是聚合层：台风路径、火山、洪水、滑坡、野火等事件由上游机构提供（如 JTWC、USGS、地方气象部门）。上游数据的许可可能不同，事件对象中的 sources[].url 指向原始出处，引用时应一并保留。
本项目加工
  • 类目映射：severeStorms → 台风、volcanoes → 火山、floods → 洪水、landslides → 滑坡泥石流、wildfires → 野火；
  • 每个事件只取最新几何；面要素取质心作为标记点，并计算包围盒半径用于影响范围示意；
  • 风暴类保留历史轨迹点，未来路径为趋势外推示意，不是官方预报；
  • 只保留最近 30 天内有更新的开放事件，再做时间窗过滤；
  • 地名中文翻译与单位换算（节 / 千米每小时 / 米每秒）。
再分发注意
标注“NASA EONET”并保留上游 sources 链接；不要把外推路径描述为官方预报；单个坐标点不代表完整影响范围。

本项目做了哪些加工

加工方式决定了再分发时的义务边界。以下六类加工均可在源代码中核对，不含隐藏的数据改写。

加工类型具体做法对许可的影响
聚合 把 USGS、EONET、NWS 三类事件归一到统一字段（类型、坐标、时间、来源、严重度），不做跨源去重合并。 产生的新字段由本项目生成；原始字段仍受上游条款约束。
抽样与截断 地震渲染上限 4200 条，超出按震级降序保留；历史库为人工挑选的代表性事件。 属于选择性编排，不能宣称“全量”；再分发时须保留该说明。
坐标精度分级 历史事件按点级 / 区域级 / 推测级三档标注，估算古代坐标范围；实时事件保留原始坐标，面要素取质心。 精度标签为本项目原创，再分发时应一并保留，避免读者误判。
地名与术语翻译 建立常见地名中英对照表；未收录地名保留原文，避免生造译名；单位做中文换算。 译文受本项目版权保护；原文地名仍属事实信息。
伤亡与影响表述 有争议的数字给区间或“人数不明”；不把不同来源合并为单一结论；古代数字注明口径不明。 属于本项目表述与判断，再分发时不得删去限定语。
示例数据 无实时事件的灾种展示琥珀色示例动画，标题含“示例”“非真实事件”，不计入实时统计，不参与时间窗。 完全由本项目生成，可自由再分发；但不得移除“示例”标注。
07

接口限制与请求频率

页面是纯静态前端，所有请求由访问者浏览器直接发出。刷新循环为 90 秒，仅在标签页可见时执行；配合本地缓存，实际网络请求远低于轮询上限。

接口端点触发频率本地缓存覆盖与限制
USGS /feed/v1.0/summary/all_day.geojson 每 90 秒触发一次；缓存命中时不发请求 ≤24 小时窗口 90 秒；7/30 天窗口 300 秒 全球，但各区域检测能力不均；小震可能缺失；无官方硬性配额
NASA EONET /api/v3/events?status=open&days=30 每 90 秒触发；缓存 300 秒 300 秒 近实时聚合，存在上游延迟；部分事件仅单点坐标；无 Key
NWS /alerts/active?event=Tsunami… 每轮 3 个查询（预警 / 观察 / 提示） 失败时回退上一次成功响应 仅美国 NWS 辖区；不提供波高；要求可识别 User-Agent
GDACS / NHC rss.xml / CurrentStorms.json 未接入 — 缺少 CORS 响应头，浏览器直连被拦截；不使用第三方代理规避
估算请求量

每轮约 5 个请求（USGS 1、EONET 1、NWS 3），90 秒一轮；考虑缓存后约 120–160 次/小时/客户端。打开多个标签页会成倍增加，建议只保留一个。

失败与降级

请求失败时读取 localStorage 缓存并标注“缓存”；无缓存则显示“不可用”。页面不会用示例数据填补实时空缺，示例层始终单独标注。
