## 简介

「科幻科技实现蓝图」（Blueprint of Sci-Fi Technology）是「赛博工程补完计划」的网页端模块：把行星发动机、太空电梯、曲速引擎等科幻造物，以工程蓝图的视角拆解为可实现的技术路径，配合交互式页面与地图进行浏览。

## 内容

- **工程蓝图页**：各科幻造物的结构拆解与技术路线
- **交互视图**：基于 Leaflet 的本地化地图组件
- **设计手稿**：行星发动机（棕墨手稿 / 黑白墨线）、太空电梯剖面、曲速引擎几何研究等原始设计图

## 技术

纯静态 HTML/CSS/JS（路由化单页结构），Leaflet 本地化引入、零外部依赖，直接托管于 GitHub Pages。
