## 简介

「技术演化数据库」是一个纯静态的多页 Web 项目，梳理人类文明科技的发展脉络：从技术条目、科技树、谱系传承到时间线与方法论，形成一套可浏览、可检索的知识库。

## 页面导览

- **index** —— 总览入口
- **tree** —— 科技树视图
- **lineage / midtech** —— 技术谱系与中间技术
- **timeline / progress** —— 时间线与进度
- **browse / detail** —— 浏览与详情
- **analysis / method / worldview / sop** —— 分析、方法论、世界观与 SOP

## 技术

纯静态 HTML/CSS/JS，零构建、零依赖，直接托管于 GitHub Pages，点击「试玩 / 访问」即可浏览。
