关于这个馆

// HOW IT WORKS

01 · 三类收藏

项目（游戏 / 研究·知识库 / 软件·工具）、股权投资札记、小项目研究，各有独立集合，首页统一聚合呈现。

02 · 自动更新日志

更新日志读取本站 GitHub 提交历史，每次 push 后自动出现，无需手工维护任何文件。

03 · 三视图浏览

简洁 / 看板 / 列表 三种视图，配合分类筛选与搜索；主题可在「深夜终端 / 复古纸」间切换。
