OpenStreetMap · 建筑轮廓

BUILDING FOOTPRINTS & HEIGHTS
真实 + 估算
官方链接
openstreetmap.org/copyright　·　 building 标签说明
获取方式
Overpass API 按经纬度分块拉取 way/relation[building]，缓存在 assets/osm-raw。
许可
ODbL 1.0（Open Database License）。数据本身与由它衍生的数据库都受该许可约束。
义务
必须署名「© OpenStreetMap contributors」；若对外分发衍生数据库，须以 ODbL 相同方式共享；不得暗示 OpenStreetMap 基金会为本项目背书。
本项目加工
轮廓抽稀并量化到 0.5 m；高度依次取 height → building:levels × 3 m → 按建筑类型估算 （浙江片区真实高度占比 5.2%，悉尼约 31%）；按空间分块合批成少量 Mesh；景点页对与精细模型重叠的体块按半径剔除。
再分发 / 商用
可商用。发布渲染截图或视频属「作品（Produced Work）」，署名即可；直接分发本项目烘焙出的 js/*-bld.js 等数据文件，则须按 ODbL 提供。
精度提示：轮廓来自志愿者的手工测绘，城市之间疏密差异很大；缺 height 标签时的高度是估算值，不适用于日照、消防或工程计算。
03

OpenStreetMap · 水系

WATER POLYGONS & WATERWAYS
真实几何
官方链接
openstreetmap.org/copyright　·　 water / waterway
取用对象
natural=water、water=lake/river/pond 多边形（含内环）；waterway=river/canal 中心线。
许可 / 义务
ODbL 1.0；署名与相同方式共享义务同上。
本项目加工
多边形带洞三角化后压平为水面；河道中心线按 Ramer–Douglas–Peucker 抽稀（浙江容差约 0.0022°，约 220 m）； 河宽优先取 width 标签，缺失时按河流名称表赋值；水面高程取「中心线与左右岸三点最低值」再加 0.8–1.2 m， 再按「现代 DEM + 重建海平面」推断历史岸线（见 06）。
再分发 / 商用
与建筑相同：作品署名即可，数据文件再分发须遵循 ODbL。
精度提示：水面高程是为贴合 DEM 湖盆而反推的近似值，不等于实测水位；历史岸线是模型推断，不是考古结论。

OpenStreetMap · 道路

HIGHWAY NETWORK
真实走向
官方链接
openstreetmap.org/copyright　·　 highway 标签说明
许可 / 义务
ODbL 1.0；署名 + 衍生数据库相同方式共享。
本项目加工
按道路等级取渲染宽度（约 6–26 m），沿中心线生成带状面；未做立交、桥梁架空与隧道分层， 因此高架与地面路在视觉上会压在同一层。
再分发 / 商用
同上。宽度是按等级赋值的视觉参数，不是实测路宽。
精度提示：大道与小巷的真实宽度差异远大于本项目的分级；页面上的路宽仅用于辨识路网结构。
05

AWS Terrain Tiles（Terrarium DEM）

ELEVATION · MAPZEN JOERD
真实高程
官方链接
registry.opendata.aws/terrain-tiles　·　 joerd 署名文档
数据构成
由 Mapzen 的 joerd 管线汇总全球多套 DEM 生成：NASA SRTM、USGS GMTED2010 / NED、NOAA ETOPO1、GEBCO 等， 以 Terrarium PNG 瓦片发布，AWS Open Data 免费托管。
许可
上游数据多为公有领域或开放许可；AWS 注册页把许可指向 joerd 的 attribution 文档。 再分发衍生作品时应保留该文档要求的上游来源说明。
本项目加工
按瓦片级别抓取（浙江 z10 / 片区 z12；巴黎与悉尼 z13，约 11 m 采样）； 用 h = R×256 + G + B/256 − 32768 解码，双线性重采样到规则网格（浙江 780 m / 60 m）， 再编码为 int16 + base64 内嵌进 js/dem*.js，运行时 atob 解码，零网络请求。
再分发 / 商用
一般可自由使用与商用；保留上游署名；不提供精度担保。
精度提示：DEM 是地表模型而非建筑表面，城区高程受树冠与建筑影响；巴黎、悉尼的 11 m 采样仍不足以表达台阶与堤岸。

历史文献与考据

HISTORICAL REFERENCES
推断 / 参考
参考书目
谭其骧主编《中国历史地图集》（中国地图出版社）；邹逸麟《中国历史地理概述》；浙江省文物考古研究所《河姆渡》； 以及全新世海侵与杭州湾岸线演变的相关研究。
许可
以上均为受著作权保护的出版物。本项目只参考其结论与时代框架，不复制图版、扫描件或成段文字； 页面中的历史叙述为自行撰写的概述。
本项目加工
把九个时代抽象为一组参数（海平面、岸线退缩、潟湖封闭、湖面、河口、淤积、围垦）， 再用「现代 DEM + 该参数」生成对应的海面与岸线；城池、海塘、事件以标注点表示。 这是一种可交互的示意模型，不是历史地理信息系统（HGIS）的复原成果。
再分发 / 商用
本项目自撰的文字与参数模型可随项目分发；若你要引用原书观点或图版，请自行核对版本、页码并遵守原书版权。
重要：本页书目是阅读与叙述的依据，不是逐条脚注。海岸形态、湖沼范围与围垦时序在学界仍有分歧，页面上的历史层不应被当作史实结论引用。

巴黎地标形制与尺寸

LANDMARK MASSING
手工近似
依据
各建筑的公开高度、面宽、轴线与平面格局（例如埃菲尔铁塔 330 m、圣母院尖塔 96 m、凯旋门 50 m）， 以及公开照片中可观察到的体块关系。
许可
建筑尺寸与形制属事实性信息，本项目未使用任何受版权保护的测绘图、模型或照片贴图； 全部几何为代码程序化生成。
本项目加工
用基础体块 + 程序化构件重建可辨识特征：埃菲尔铁塔的四条外撇塔腿与三层平台、 圣母院的双塔与飞扶壁、卢浮宫的 U 形庭院与玻璃金字塔、圣心堂的穹顶群、凯旋门的拱洞与阁楼等。 地标位置取真实经纬度，朝向按街道轴线人工设定。
再分发 / 商用
模型代码可随项目分发；不得作为测绘、工程或修缮依据。
精度提示：这是「看得出的轮廓」，不是 BIM 或摄影测量成果。细部、比例与真实建筑存在简化与偏差；圣心堂等位于山丘上的建筑，基座高度随 DEM 起伏。

真实、估算与艺术化

WHAT IS REAL

真实测量 / 公开数据

  • DEM 高程（Terrarium 瓦片，真实米数）
  • OSM 建筑轮廓、水体边界、河道与道路走向
  • OSM 标注的 height / building:levels
  • 巴黎 14 处地标的经纬度位置
  • 地标高度与主要面宽（公开数据）

估算 / 推断

  • 无标签建筑的高度（按层数或类型估算）
  • 道路宽度（按等级赋值 6–26 m）
  • 历史海岸线、湖沼范围、河口退缩
  • 水面高程（贴合 DEM 湖盆反推）
  • 地标体块的比例与细部简省
  • 市区地表色带（按高程分层设色）

艺术化处理

  • 垂直夸张：浙江 ×10、城市总览 ×3、景点页 ×1
  • 道路加宽、水面平铺、地标剔除带
  • 地面光环、悬浮标记、选中高亮
  • 雾效、光照、配色主题（铜金 / 石膏白 / 冷蓝钢 / 霓虹）
  • 历史层的事件标注与场景化叙述

垂直夸张是影响观感最大的一项：它只放大高程，不改变平面坐标。因此任何「看起来」的坡度、山势与建筑高矮对比， 都需要按该页标注的倍数还原后再判断。景点专题页使用 1:1 真实比例，就是为了让地标与周边普通建筑的高度关系保持真实。

本项目的加工链

PROCESSING PIPELINE
STEP 01
抓取与缓存

DEM 按瓦片、OSM 按 bbox 分块从公开端点拉取，原始数据留在 assets/，可复现。

STEP 02
解码与重采样

Terrarium 解码为米，双线性重采样到目标网格；OSM 几何去空点、拼环、修复绕序。

STEP 03
抽稀与量化

RDP 抽稀（河网约 220 m、建筑轮廓 0.5 m 量化），用 int16 定点存储，显著压缩体积。

STEP 04
烘焙为脚本

几何与高程编码成 base64，写成 js/*.js 全局变量，运行时零网络、可直接 file:// 打开。

STEP 05
建模与合批

建筑按空间分块合批；地标用程序化体块重建；重叠的 OSM 体块按半径剔除。

STEP 06
渲染与标注

垂直夸张、分层设色、光环与标记叠加；页面内标注数据性质与精度分级。

再分发与商用

REDISTRIBUTION
可以

离线自用、教学演示、内部汇报、公开发布截图与录屏。发布图片或视频时保留「© OpenStreetMap contributors」署名即可。

可以

商业项目中使用渲染结果。OSM 数据允许商用；three.js 为 MIT 许可，同样允许商用。

需注意

分发数据文件。把 js/*.js 中的数据文件（而非仅页面）对外提供时，这些文件属于 ODbL 衍生数据库，须以 ODbL 1.0 提供并保留署名与许可链接。

需注意

DEM 上游署名。再分发地形衍生数据时，按 joerd attribution 文档保留 SRTM / GMTED2010 / NED / ETOPO1 / GEBCO 等上游来源说明。

需注意

不要暗示背书。不得让第三方以为 OpenStreetMap、OpenStreetMap Foundation、Mapzen 或 AWS 认可、担保了本项目。

不建议

当作测绘或工程依据。垂直夸张、高度估算、水面近似与手工地标都不满足测量精度；历史层是示意模型，不能作为史实引用。

不可

移除署名后二次分发 OSM 数据。这违反 ODbL 的署名条款；也不得把 OSM 数据整体转授为更宽松的许可。
