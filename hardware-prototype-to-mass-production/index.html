0总览与使用方法

0.1 这本书解决什么问题

硬件创业团队和转型做硬件的公司，最常见的失败不是"做不出来"，而是下面几种：

  • 样机很漂亮，一开模就变形、缩水、装配不上；
  • Demo 跑通了，量产 500 台有 80 台不良，且找不到原因；
  • 委外给 ODM，样机 OK，量产偷换料、改结构，出问题互相甩锅；
  • 抄竞品抄得很像，上市被诉外观专利，渠道下架；
  • 没有变更流程，研发口头改一版，工厂还在用旧图纸做货。

本书按真实的项目推进顺序写，每一章都包含三件事：该做什么、难点坑点在哪、委外时怎么管。

0.3 一条贯穿全书的核心判断

样机 vs 量产的本质区别

样机证明"能做出来"：一个工程师、一份好料、一台调试好的设备、花三天时间，做出一台能跑的东西。

量产证明"能稳定、低成本、可追溯地重复做出来"：一百个不同工人、来料有公差波动、设备状态每天漂移，仍要做出 10 万台一致的产品。

本书 80% 的坑，都出在"用样机的思维管量产"这一件事上。

0.4 三种研发组织模式

模式适用你需要守住的底线
全自研
自有 ID/结构/电子/固件		核心技术必须自控、有长期产品线模具与测试设备投入大；要建立完整 DFM/DFT 能力
部分委外
自研核心 + 委外 ID 或结构或 PCBA		大多数创业团队的最优解接口定义清楚：你给 PRD 与验收标准，对方交源文件与测试原始数据
ODM / OEM
整机方案商出货		快速上市、非核心品类、渠道型公司锁关键料白名单、锁源码与模具权属、锁 PCN/ECN 通知义务
委外不是甩活

委外的本质是把三件事拆清楚：设计责任谁担、制造责任谁担、验收标准谁定。这三件事没写进合同，出问题时你一定会买单。

1需求与竞品对标：从"模仿"走到"改良"

1.1 第一步：把"做个类似某某的"翻译成技术指标

老板或市场最常见的需求表达是"做个跟 ×× 差不多的，便宜点，好看点"。这句话不能直接进研发，必须翻译成可验证指标。

模糊表达翻译成
"跟 ×× 差不多"对标机型清单 + 尺寸/重量/性能参数表
"便宜点"目标 BOM 成本、目标售价、毛利率、模具预算上限
"好看点"CMF 方向、目标人群审美、与竞品的差异点（线条/材质/配色）
"质量要好"可靠性指标（跌落/寿命/温升）、返修率目标（如 <1%/年）

1.2 竞品五维拆解

买 2–3 台主要竞品（含一台高端标杆、一台低价走量），由 ID、结构、电子、固件、工艺五人各拆一遍：

  1. 造型维度：体量、比例、握持、按键位置、视觉重心；
  2. 功能维度：功能清单、交互路径、响应时延、极限工况表现；
  3. 结构维度：拆件数、卡扣/螺丝数量、装配顺序、可维修性；
  4. 材料工艺维度：壳体料、表面处理、关键件供应商痕迹（丝印/模号）；
  5. 成本维度：按 BOM 大类估算（主控、屏、电池、结构件、包材），反推其成本结构。
最有价值的产出不是"它怎么做"，而是"它哪里会坏"

拆解时重点记录失效模式：哪里最薄、哪里应力集中、哪里散热最差、哪个接口最容易松、用户最容易抱怨什么（去电商差评区、售后论坛、维修店找答案）。竞品的缺陷，就是你的差异化空间。

1.3 合法逆向的边界（非常重要）

可以做 / 不能做
  • 可以做：购买市售产品自行拆解、测量尺寸、分析工作原理、测试性能、研究失效模式、做专利检索与规避设计。
  • 不能做：复制外观曲面与装饰设计（外观专利/著作权风险）、反编译或复制固件代码（版权/商业秘密）、使用对方的技术文档与图纸、仿冒商标与包装装潢。
  • 灰色高危：找方案商买"公模 + 公版固件"再贴牌——能用，但你没有差异化，也没有 IP，价格战里最先死。

操作建议：立项时同步做一次 FTO（自由实施）检索，列出竞品专利的权利要求要点，标注高风险项，交给研发做规避设计。预算有限时至少检索：目标市场的外观专利 + 核心功能对应的发明专利。

1.4 需求分层：Kano 模型实操

层级含义处理方式
基本需求没有会非常不满必做，且要做到位（如安全、基础功能稳定）
期望需求做得越好越满意按成本排序，做性价比最高的几项
魅力需求没有不会不满，有则惊喜作为差异化卖点，控制在 1–2 个，避免拖垮成本与进度

第 1 章出门检查清单
  • PRD（产品需求文档）已定稿并签字，含性能/尺寸/功耗/成本/认证目标
  • 竞品对标报告：五维拆解 + 缺陷清单 + 差异化假设
  • 专利 FTO 初筛报告 + 规避设计方向

1.6 难点与坑点

坑 1：只给"要像 ××"，不给预算

结果 ID 按高端机做造型，成本按百元机控，后期大量返工。立项时必须同时给出目标成本和造型方向。

坑 2：逆向只拆硬件，不研究使用场景

得出错误性能目标（例如照搬竞品续航，却忽略了对方用了更大电池和更低功耗屏）。必须做真实场景测试，而不是照抄参数表。

坑 3：把"抄"写进委外合同

设计公司照抄竞品，你承担全部法律风险。合同写"参考市场趋势做原创设计，需通过原创性审查"。

2产品定义与工业设计：ID / CMF / 结构预演

2.1 目标：在画图阶段就把量产算进去

工业设计（ID）最容易犯的错，是交付一套漂亮的效果图，然后说"结构你们想办法"。正确的做法是：ID 出图的同时，结构、工艺、采购同步介入。

2.2 ID 概念阶段

  • 出 2–3 个方向的草图，做体量判断；
  • 用 3D 打印或油泥/泡棉做草模，验证握持、尺寸感、视觉重心（渲染图骗人，手上的体量感不骗人）；
  • 与内部堆叠图（主板、电池、电机、传感器的占位）同步核对，避免"造型做完了发现装不下"。

2.3 CMF：颜色 / 材料 / 表面处理

CMF 是"渲染好看、量产翻车"的重灾区，必须提前锁定量产可实现的工艺。

工艺效果量产风险
注塑原色（素材）成本低、耐磨颜色受原料批次影响，色差需管控
喷涂颜色自由、可做手感漆色差、橘皮、掉漆、附着力、环保（VOC）
阳极氧化（铝）金属质感、硬度高批次色差明显、遮蔽难、成本高
电镀 / 真空镀高亮镜面易划伤、指纹、良率偏低
IML/IMD 转印图案耐久模具与膜片成本高、起订量要求
CMF 三大翻车点
  • 3D 打印样 ≠ 注塑量产：树脂样件的光泽、手感、颜色与 PC/ABS 完全不同；
  • 色板喷漆 ≠ 量产喷涂：手工喷和自动线喷的膜厚、均匀度差很多；
  • 没定义色差标准：必须约定标准光源（D65）、ΔE 上限（常见 ΔE≤1.0~1.5 目视可接受）、上下限色板（Limit Sample）并双方签字封样。

2.4 结构预演：早期 DFM 的真正价值

在 3D 数模阶段就请模具厂/结构老工程师介入，重点评：

  • 拔模：外观面一般 1°–3°，纹理面按纹理深度加大（蚀纹每 0.025mm 约加 1°）；
  • 壁厚：均匀为主，常见 ABS/PC 1.8–2.5mm，避免厚薄突变导致缩水、缩痕；
  • 倒扣：能做斜顶/滑块但要加钱，尽早在图纸上消除；
  • 分型面与夹线：夹线位置是否落在外观正面；
  • 公差链：多个零件累加公差后，装配是否还合格（段差、间隙、晃动）；
  • 装配顺序：能否自上而下一次装完，是否需要翻转、是否干涉螺丝刀。

2.5 人机与场景：不要只做"标准人手"

常被忽略的场景
  • 戴手套操作、湿手/油污手操作；
  • 左撇子用户、儿童与老人手型；
  • 高温/低温环境戴护具；
  • 单手操作、盲操作（不看屏幕能否按对）；
  • 强光下可读性、夜间使用是否刺眼。

2.6 委外做 ID 的管控要点

合同里必须写清的四条
  1. 交付物包含可量产的 3D 数模（不是只交渲染图/STL），并注明建模公差与曲面质量；
  2. 包含结构可行性评审与至少一轮 DFM 修改；
  3. 包含源文件交付（3D 源文件、分层文件），知识产权归委托方；
  4. 原创性承诺条款：若因抄袭导致侵权，由设计方承担责任。

2.7 本章交付物与检查清单

第 2 章出门检查清单
  • ID 方案已评审，ID/结构/电子/工艺/采购/专利六方签字
  • 3D 数模完成，通过早期 DFM 评审，问题单已闭环
  • CMF 规范定稿：色号、工艺、纹理、色差标准、封样色板
  • 堆叠可行：内部件占位、散热空间、天线净空已核对
  • BOM 雏形与成本区间达成
  • 人机场景清单已验证（至少含极端手型与极端环境）

3Demo 与概念样机：用最低成本暴露最大问题

3.1 三种样机，目的完全不同

类型目的典型做法
外观样验证造型、CMF、人机、包装直觉3D 打印、CNC、硅胶复模、喷漆手板
功能样 / 原理样验证核心功能、算法、交互是否成立开发板、飞线、外挂电源、临时结构
综合样 / 类工程样软硬联调、走向 EVT 前的最后验证接近量产料、接近量产结构、可用固件

Demo 的意义不是"给客户展示"，而是尽快把最大的不确定性打掉。判断标准只有一个：这一版样机回答了哪个关键问题？如果回答不了任何问题，就是在浪费时间。

3.2 外观样：做得像，但别被"像"骗了

  • 3D 打印（SLA/SLS）适合造型与装配验证；CNC 适合强度与精度验证；硅胶复模适合做 5–20 套小批量外观件。
  • 喷漆手板可以实现量产喷涂 80% 的视觉效果，但耐磨、附着力、色差无法验证。
  • 做包装直觉测试时，连彩盒一起做出来，摆到货架上拍照看第一眼效果。

3.3 功能样：能跑通 ≠ 能贴片

功能样的三个经典幻觉
  1. 开发板跑通 ≠ PCBA 可量产：开发板用了大封装、宽间距、外置晶振与调试口，量产板要做小型化与公司、去掉调试依赖。
  2. 飞线调试成功 ≠ 量产能复现：飞线的走线阻抗、屏蔽、接地都不同于 PCB，量产版本的 EMC 与信号完整性要重测。
  3. 实验室环境正常 ≠ 现场正常：功能样常在常温、稳压电源、无干扰环境下测试，一上电池、一进高温、一接电机就出问题。

建议：功能样阶段就把电源方案、电池、电机/大电流负载、无线模块拉进来做真实联调，这是最容易在后期爆雷的四项。

3.4 综合样：材料不能"差不多"

样机材料失真导致测试失真
  • 用普通 ABS 代替耐高温 PC/PC+ABS：高温测试通过，量产变形；
  • 用铝件代替镁合金/压铸：重量与强度数据失真；
  • 用手工焊接的模块代替量产 PCBA：散热路径完全不同，温升数据不可用。

规则：凡是会影响测试结论的零件，必须用接近量产的材料与工艺制作，并在样机报告里注明材料偏差。

3.5 委外做 Demo 的坑

委外样机合同的必备条款
  • 明确材料牌号（如 PC-110、ABS 757）、公差带、表面处理工艺；
  • 明确测试条件（温度、负载、时长、样本数），否则对方只交"能开机"的样机；
  • 要求交付调试记录、接线图、固件版本、问题清单，而不是只交付一台机器；
  • 约定样机阶段发现的重大问题，由谁承担改版费用。

3.6 出门检查清单与决策门

第 3 章出门检查清单
  • 外观样完成，造型/CMF/人机问题已记录
  • 功能样完成，核心功能与算法可行性已验证
  • 综合样完成，软硬联调通过，关键参数有基线数据
  • 材料偏差说明已写进样机报告
  • Demo 问题单已分级（P0/P1/P2）并指定责任人
  • 已决策：进入 EVT / 推翻架构 / 暂停项目

4EVT 工程样机验证：证明"原理成立"

4.1 EVT 的定位

EVT（Engineering Verification Test）回答一个问题：这套架构和原理能不能work？ 允许手工板、临时结构件、未定型的固件，只要核心功能与关键指标能验证。

数量
常见 5–20 台（复杂机械/医疗设备按行业，可能 2–5 台）
允许
手工焊接、飞线、3D 打印结构件、开发板模块
不允许
用 EVT 数据直接判定量产可行性

4.2 EVT 必做的八件事

  1. 核心功能全项测试：按 PRD 的功能清单逐条过，不漏项；
  2. 软硬件联调：固件与硬件驱动、传感器标定、通信协议打通；
  3. 关键器件选型验证：主控算力余量、电源带载能力、无线性能、传感器精度；
  4. 功耗与热初步评估：待机/工作/峰值电流，关键器件温升（先用热电偶摸底）；
  5. 结构装配验证：能否装起来、拆装是否可行、有无干涉；
  6. 初步风险识别：EMC 风险点、天线净空、散热路径、单一来源物料；
  7. DFMEA 初版：列出潜在失效模式与严重度，指导 DVT 重点；
  8. 问题单闭环：P0 问题（功能不达标/安全风险）必须解决才能进 DVT。

4.3 EVT 阶段的典型坑

坑 1：样品料陷阱

研发用的是代理商送样、拆机料或小批量采购料，参数处于规格书"典型值"。量产后用大批量料，参数分布更宽，可能落在边界。EVT 阶段就要开始问：这个料量产买得到吗？几周交期？有几个供应商？

坑 2：手工焊接的假数据

手工焊的焊点、散热过孔、接地都优于或劣于量产回流焊，温升与 EMC 数据都不可靠。EVT 的电气数据只用于"判断方向"，不能用于"判定合格"。

坑 3：固件没有版本管理

多人改固件、口头传版本，导致"测的是哪一版"说不清。EVT 起就要建固件版本库 + 版本与硬件版本对应表。

坑 4：只测一台，且是最好的一台

应至少测 3 台以上，覆盖器件批次差异；并对关键参数做边界测试（电压上限/下限、温度上下限、负载极限）。

专业EVT 关键动作

5DVT 设计验证：把"设计"钉死

5.1 DVT 的定位

DVT（Design Verification Test）回答：这个设计在真实环境和量产工艺下，是否稳定可靠？ 此时结构应接近量产（试模件），PCB 用正式版本，固件接近量产版本。

最大的纪律：模具冻结

DVT 开始前必须完成设计冻结（Design Freeze）。若 DVT 期间还在改结构/改板，改完后所有可靠性、环境、EMC 测试必须重跑——这是项目延期最常见的原因，一次改模往往连带 4–8 周。

5.2 可靠性与环境测试清单（通用模板）

类别典型项目说明
机械跌落、振动、机械冲击、按键/接口寿命、插拔寿命跌落按整机重量与包装定高度与面数
气候高温工作/贮存、低温工作/贮存、恒温恒湿、温度循环、热冲击关注凝露、材料脆化、电池性能
防护防尘防水（IP 等级）、盐雾（金属件/沿海）IP 等级需明确测试方法与判定
寿命整机耐久、疲劳、老化（常温/高温带电老化）老化时长按行业惯例，常 24–168h
化学耐汗液/化妆品/清洁剂、耐磨（RCA/钢丝绒）穿戴类、手持类必做
包装运输ISTA/ASTM 运输模拟、堆码、仓储出口与电商件必做
测试样本数的现实做法

严格统计学抽样成本高，创业团队常用折中：关键破坏性测试 3–5 台，非破坏性测试全样，寿命测试取 3 台以上并接受"零失效"判定。但一定要写清楚样本数与判定准则，避免后期争议。

5.3 EMC / 无线 / 安规：越早摸底越省钱

最贵的雷：DVT 末期才测 EMC

辐射/传导超标时，整改手段通常是：改 PCB 叠层与地平面、加屏蔽罩、改滤波、调整线缆与接地方式——这些都意味着改板 + 改结构，周期以月计。正确做法：EVT 阶段就做预扫描（哪怕用近场探头 + 频谱仪粗测），DVT 至少做一次完整预测试。

项目关注点
EMC辐射发射、传导发射、静电 ESD、浪涌、EFT、电压跌落
无线发射功率、灵敏度、频偏、SAR（贴近人体产品）、共存干扰
安规耐压/绝缘、漏电流、爬电距离与电气间隙、温升、异常测试
电池过充过放短路保护、UN38.3、IEC 62133（按目标市场）

5.4 试模：T1 / T2 / T3 的节奏

T1
模具首次试模，看能否出完整件，重点是结构完整性、填充、明显缺陷
T2
修正后试模，评估尺寸、装配、外观（缩水、夹线、披锋、气纹）
T3
小批量试产，验证模具稳定性与重复精度，进入 DVT/PVT 用料
试模现场必须记录
  • 注塑参数：料温、模温、射速、保压压力与时间、冷却时间、周期时间；
  • 缺陷照片与位置：缩水、翘曲、气纹、烧焦、披锋、顶白、拉伤；
  • 关键尺寸测量报告（CMM 或 2.5D），与设计公差对照；
  • 模具动作：滑块/斜顶是否顺畅、顶出是否平衡、有无异常噪音。

5.5 DVT 阶段的结构专项

  • 装配验证：用工装/夹具模拟量产动作，验证节拍与防呆；
  • 公差边界验证：故意用上下限尺寸的零件装配，看是否仍合格（这是量产稳定性的关键）；
  • 可维修性：拆机时长、是否需要专用工具、是否损伤卡扣；
  • 异响与手感：按键行程与力值、旋钮阻尼、晃动异响（常被投诉但难量化，建议做主观评价小组 + 力值/位移曲线量化）。

6PVT 与 NPI 中试：在量产线上证明能重复做

6.1 PVT 的定位

PVT（Production Verification Test）／中试：用量产工艺、量产线、量产工装、量产人员跑一批，验证良率、直通率、测试覆盖与一致性。这是从"研发做出来"到"工厂造出来"的分界线。

数量
消费电子常 50–200 台；结构复杂或高可靠行业（汽车、医疗）按行业规范，可能要求更多
关键
不能由研发工程师"帮着做"，必须由产线工人按 SOP 做
产出
工艺参数基线、直通率、不良 Top 问题、SOP 与检验规范定稿

6.2 NPI 新品导入的标准动作

  1. 文件包发布：冻结 BOM、CAD/装配图、Gerber、固件版本、SOP、测试规范、包装规范、标签与追溯规则；
  2. 工装治具到位：SMT 钢网、载具、ICT 针床/治具、FCT 治具、点胶治具、锁附治具、老化架；
  3. 首件确认（FAI）：首件全尺寸 + 全功能检验，研发、品质、工艺三方签字；
  4. 小批跑线：按节拍生产，记录每个工位的工时、不良、瓶颈；
  5. 测试系统验证：SPI/AOI/X-Ray（SMT）、ICT、FCT、老化、OQC 全跑通；
  6. 直通率统计：设定目标（消费电子常以 95%–98%+ 为参考，具体按产品复杂度与工艺能力定），不达标则退回整改；
  7. 包装运输验证：整机 + 包装一起做运输测试。

6.3 SMT 与 PCBA 的关键工艺参数

工序要固化的参数
锡膏印刷钢网厚度与开口、刮刀压力/速度/角度、脱模速度、清洗频次
贴片吸嘴型号、吸取高度、贴装压力、视觉识别参数、料站核对
回流焊炉温曲线（预热/恒温/回流/冷却峰值与时间）、链速、氮气浓度
检测SPI（锡膏厚度/面积）、AOI（偏移/立碑/少件）、X-Ray（BGA 空洞率）
分板/清洗分板应力、洗板水与洁净度、离子残留
换线必重验

炉温曲线、钢网版本、贴片程序是按"某一台设备 + 某一套参数"调出来的。换产线、换工厂、甚至换季节（车间温湿度变化）都要重新验证工艺参数，否则虚焊、偏移、锡珠会集中爆发。

6.4 中试不良分析：把 Top 3 打掉

中试的价值在于暴露问题，必须做不良 Pareto 分析，按不良数量排序，集中资源打前三项：

  • 虚焊/少件/偏移 → 查钢网开口、炉温、元件封装与焊盘设计；
  • 功能误判/测试不稳定 → 查测试治具接触、测试程序阈值、被测件一致性；
  • 装配间隙/段差/异响 → 查公差链、定位基准、锁附顺序与扭矩；
  • 外观缺陷（划伤、脏污、色差）→ 查搬运防护、作业手法、来料包装。

6.5 委外工厂的现场管控

中试与首批量产，建议驻厂
  • 重点站位：SMT 炉后、注塑首件、总装关键工位、FCT、老化、OQC；
  • 要日报：产出数、直通率、不良 Top 3、返修数、停机时长、物料批次；
  • 三阶段签样：功能样 → 性能样 → 量产一致样，每阶段双方签字封样，作为后续争议基准；
  • 工厂说"别的项目也这么做"时，坚持做本项目的工艺验证，不通用套用。

7DFM / DFA / DFT / DFC：可制造性四件套

7.1 四个词的区别

缩写关注典型问题
DFM 可制造性零件能不能做出来倒扣、缩水、拔模不足、公差过严
DFA 可装配性能不能高效装起来零件数过多、无防呆、需翻转装配
DFT 可测试性能不能测出来好坏无测试点、无法覆盖关键信号
DFC 成本设计能不能便宜做出来过度设计、单一来源料、多余工序

7.2 注塑件 DFM 要点

  • 壁厚均匀：厚薄过渡要渐变，避免缩痕与翘曲；加强筋厚度取壁厚的 0.5–0.7 倍以防表面缩痕；
  • 拔模角：光面 1°–3°，蚀纹面随纹理加深；深腔与长型芯加大；
  • 圆角：内壁转角做 R 角，减少应力集中与模具磨损；
  • 浇口与熔接线：浇口位置避开外观面与受力区，熔接线不落在强度薄弱处；
  • 螺丝柱：外径与内孔比例合理，避免缩水与开裂，考虑加火山口；
  • 卡扣：根部做圆角，扣合量、插入力与保持力需计算并用试模验证。

7.3 钣金与压铸要点

  • 钣金：折弯半径不小于板厚、孔到边距离足够、焊接可达性、避免极小间距孔；表面处理顺序（先焊后喷 or 先喷后装配）要写清。
  • 压铸：壁厚均匀、避免深腔与厚大部位、考虑脱模与模具寿命，气孔是常见缺陷（影响强度与后续加工）。

7.4 PCBA 的 DFM / DFT

  • 焊盘与间距：元件间距满足贴片机与 AOI 检修空间；细间距器件（0.4mm pitch 以下 BGA/CSP）需评估工厂能力；
  • 测试点：关键网络（电源、地、复位、时钟、通信总线）预留测试点，直径与间距满足 ICT 针床要求；
  • 拼板与工艺边：拼板方式（V-Cut/邮票孔）、工艺边宽度、Mark 点（全局与局部）位置；
  • 钢网开口：按封装给出开口比例与阶梯钢网需求（大元件与小元件共存时）；
  • 可返修性：BGA 周围留出返修空间，热敏感器件远离高温区；
  • 三防与点胶：涂覆避让区（连接器、测试点、散热面）要在图上标出。
DFT 缺失的代价

没有测试点 → 只能靠功能测试，坏机现象能发现但定位不了根因；没有 ICT → 焊接缺陷只能到 FCT 才发现，返修成本高；没有边界扫描/JTAG → 固件无法在线烧录与调试，量产烧录效率低。DFT 在原理图阶段就要做，事后补不上。

7.5 DFA：装配是成本大头

  • 减件：每减少一个零件，就减少一次采购、一次检验、一次装配、一次失效机会；
  • 防呆（Poka-Yoke）：结构设计成"装反就装不进去"，不对称定位柱、异形孔；
  • 螺丝统一：全机尽量用同一规格螺丝，减少工具切换与错件；
  • 自上而下装配：避免中途翻转，减少夹具与工时；
  • 扭矩与顺序：规定锁附扭矩与顺序（对角锁紧），防止变形与密封不良。

7.6 DFC：成本是设计出来的

降本的四个杠杆
  1. 器件级：寻找 pin-to-pin 替代料、国产替代、去掉冗余器件；
  2. 结构级：减件、减少螺丝、合并支架、降低表面处理等级；
  3. 工艺级：减少工序（如免喷涂、免二次加工）、提高良率、缩短节拍；
  4. 规模级：集中料号提高议价、模具摊销、包装与物流优化。

注意：降本必须走 ECN + 重验证，禁止"悄悄换料"。

ODM 最常见的三种"暗操作"

  2. 交付"通用版"固件：只给烧录文件不给源码，二代迭代被卡脖子。对策：合同写明源码/中间件交付与交付时间节点。
  3. PCN 不通知：供应商停产换料，产品性能悄悄改变。对策：合同写明任何物料变更需提前书面通知并获同意。

8.4 联合测试用例库：别让他按"通用标准"验收

ODM 常按行业通用标准测试，结果"全部合格"，但你的用户场景挂了。做法：把你在 Demo/EVT 阶段积累的真实场景样本、压力脚本、失效模式清单提供给 ODM，作为联合测试用例库，写进验收附件。

8.5 供应商管理

  • 分级：战略供应商（定制件/长交期）、重要供应商（关键元器件）、一般供应商（标准件包材）；
  • AVL 合格供应商名录：进 AVL 需审厂（产能、设备、质量体系、环保合规）；
  • 双源策略：关键料至少两家，避免断供与被独家涨价；
  • 来料检验 IQC：按 AQL 抽样，关键件全检或加严；记录批次号，建立追溯链；
  • 交期管理：识别长交期料（常见 8–20 周，主控/屏/电池/定制件），用"滚动预测 + 安全库存"覆盖。

8.6 本章检查清单

第 8 章出门检查清单
  • PRD 已含全部硬指标，双方签字确认
  • 合同条款覆盖：费用、IP、模具、物料、验收、罚则、保密、EOL
  • 关键料白名单与 AVL 已建立，双源策略已定
  • 联合测试用例库已移交并被对方采纳
  • 驻厂/第三方 QC 机制、日报机制已建立
  • 三阶段签样（功能样/性能样/量产一致样）已封样

9模具、工装与工艺固化

9.1 模具是最大的沉没成本与最大的风险

一套模具费用从几万到数百万不等，一旦开模，改动成本极高。开模前必须完成：DFM 评审、公差分析、模具方案评审（穴数、浇口、冷却、顶出、钢材）。

评审项关注
穴数按产量与单件成本平衡；多穴需注意穴间一致性
钢材按产量与塑料特性选（如预硬钢 vs 淬火钢），影响寿命与成本
浇口形式侧浇口/点浇口/热流道，影响外观、流痕与料耗
冷却水路布置影响周期与变形，是产能瓶颈的隐形杀手
顶出顶针布局与平衡，避免顶白与变形

9.2 试模到验收的节奏控制

  1. T1：能出件，看大问题；
  2. T2：尺寸与装配，看关键配合；
  3. T3：小批连续跑，看稳定性（连续生产数百模，看尺寸漂移与缺陷率）；
  4. 模具验收：连续生产若干模次无异常，尺寸报告合格，双方签模具验收报告。
模具寿命与维护责任要提前写

模具寿命（多少模次）、日常保养由谁做、非正常损坏谁赔、模具存放与迁移权（想换厂时能否拉走）——这几条不在合同里，后期极易扯皮。模具所有权归出资方是最基本的一条。

9.3 工装治具清单

  • SMT：钢网、载具/托盘、支撑治具；
  • 测试：ICT 针床/治具、FCT 治具（含气动/针床/夹具）、老化架、屏蔽箱（无线测试）；
  • 装配：定位治具、点胶治具、压合治具、锁附治具（含扭矩枪校准）；
  • 检测：外观检验治具（限度样品 + 光照箱）、尺寸检具（通止规、检具）；
  • 包装：包装治具、称重/防漏放检测。

9.4 工艺固化：把"老师傅经验"变成参数

必须形成文件的工艺参数
  • 注塑：料温、模温、射速、保压、冷却时间、周期时间；
  • SMT：钢网型号与版本、刮刀参数、炉温曲线编号、链速；
  • 点胶：胶量、气压、时间、固化条件；
  • 锁附：螺丝规格、扭矩值、顺序、批头型号；
  • 喷涂/丝印：膜厚、烘道温度与时间、网版版本；
  • 烧录：固件版本、烧录工具版本、序列号写入规则、校验方式。

每一条都要写进 SOP，且规定"变更必须走 ECN"。没有固化的工艺，换个人就换批质量。

9.5 本章检查清单

第 9 章出门检查清单
  • 模具方案评审通过，钢材/穴数/浇口/冷却确定
  • T1–T3 试模完成，尺寸报告与缺陷整改闭环
  • 模具验收报告签字，寿命与维护责任写入合同
  • 工装治具全部到位并验收（含精度与安全防护）
  • 关键工艺参数固化为 SOP，作业员培训与考核完成
  • 设备点检与保养计划建立

10量产爬坡与质量管理

10.1 爬坡节奏：不要一步到位

量产启动后按 50% → 80% → 100% 产能阶梯放行，每一级盯三个指标：直通率、返修率、客诉率。指标稳定后再上一级。

爬坡期的典型错误
  • 为赶交期直接满产 → 工艺问题被产能掩盖，批量不良在客户端爆发；
  • 首批不做 FAI 就放行 → 不良责任归属不清，工厂与研发互相推；
  • 只看产量不看直通率 → 表面上发货了，实际是靠大量返修堆出来的。

10.2 质量控制的四道门

环节做什么要点
IQC 来料检验按 AQL 抽样检验来料记录批次号；关键件加严或全检
IPQC 过程检验首件、巡检、关键工位抽检首件不签不量产；巡检频次按风险定
FQC/OQC 成品检验功能、外观、包装出货检验外观用限度样品 + 标准光源
ORT 可靠性抽检持续做可靠性抽检量产中定期抽做寿命/环境，防止质量漂移
AQL 抽样速记

常用 GB/T 2828.1 / ISO 2859-1，一般检验水平 II，AQL 常见设定：致命缺陷 CR=0，主要缺陷 MA=0.65 或 1.0，次要缺陷 MI=1.5 或 2.5。具体数值按产品风险与行业惯例定，并写进检验规范。致命缺陷零容忍是底线。

10.3 SPC 与过程能力

  • 对关键特性（CTQ）建立控制图：关键尺寸、扭矩、电流、电压、功能参数；
  • 用 CPK 衡量过程能力，量产常见要求 CPK≥1.33（关键特性可要求更高）；CPK 不足时靠工艺改善或放宽公差（放宽需设计确认）；
  • 设定异常判定规则（如连续 7 点单侧、超控制限）与反应计划（停机、隔离、追溯）。

10.4 追溯体系

发生召回时，你只能靠它救命
  • 唯一序列号：整机 SN，写入固件与标签；
  • 批次绑定：SN ↔ 生产日期/班次/产线 ↔ 关键料批次（主控、电池、屏）↔ 固件版本；
  • 数据留存：测试记录、维修记录、出厂检验记录按 SN 存档；
  • 反向追溯：某批电池出问题，能反查出哪些 SN 用了这批电池。

10.5 异常处理：8D 报告

  1. D1 成立小组；D2 描述问题（5W2H，量化）；D3 临时对策（隔离/筛选/返工）；
  2. D4 根因分析（5Why、鱼骨图、故障树，必须到"为什么发生 + 为什么没被发现"两层）；
  3. D5 永久对策（设计/工艺/管理层面）；D6 实施与验证；
  4. D7 预防再发（更新 FMEA、SOP、检查表、设计规范）；D8 关闭与奖励。
8D 最常见的失败

根因只写到"作业员疏忽""来料不良"就停了，对策是"加强培训""要求供应商注意"。这不是根因。必须追问：为什么系统会允许疏忽发生？为什么检测没拦住？

10.6 本章检查清单

第 10 章出门检查清单
  • 爬坡阶梯计划与放行标准已定
  • 四道检验（IQC/IPQC/OQC/ORT）规范与表单齐备
  • 关键特性 CTQ 清单 + SPC 控制图 + CPK 目标
  • 追溯体系：SN、批次绑定、数据留存、反向追溯可用
  • 8D 流程与 FRACAS 问题库运转，重大异常有闭环记录
  • 限度样品、标准光源、检验员资格认证到位

11变更管理与版本冻结

11.1 为什么要专门写这一章

小公司最常见的混乱来源：口头改需求、微信发图纸、工厂用旧版生产、研发改了料没通知采购。变更不可怕，失控的变更才可怕。

11.2 冻结的三个层级

冻结含义时点
设计冻结3D/2D/原理图不再改DVT 启动前
BOM 冻结料号、品牌、型号、用量确定PVT 启动前
工艺冻结SOP、参数、工装版本确定MP 放行前

冻结不等于不能改，而是改必须走流程。

11.3 ECN / ECR 流程

  1. ECR 变更申请：提出人写清变更内容、原因、期望收益；
  2. 影响评估：由工程、品质、采购、生产、认证、售后联合评估——图纸、模具、库存、在制品、工装、认证、软件兼容性、客户批准需求；
  3. 验证：小批验证或可靠性重测（换料必须重跑相关测试）；
  4. 批准：按变更等级分级审批（重大变更需项目负责人/客户批准）；
  5. ECN 发布：更新文件版本，通知所有相关方，明确切换时点与旧料处理；
  6. 切换与追溯：记录切换批次的 SN 区间。
变更的隐藏成本
  • 库存与在制品：旧料、半成品、成品如何处理？报废还是混线？
  • 认证影响：换了结构性器件或关键元器件，认证可能需要补充测试甚至重做；
  • 客户批准：B2B 客户通常要求提前书面通知，擅自变更可能触发索赔。

11.4 版本管理实务

  • 文件版本号规则（如 A/0、B/1），图纸、BOM、SOP、固件统一规则；
  • 文件发布平台唯一，禁止用微信群发图纸；旧版本必须作废并可查；
  • 固件版本 ↔ 硬件版本 ↔ 测试版本三方对应表；
  • 工厂现场只允许存在受控版本文件，定期稽查。

11.5 本章检查清单

第 11 章出门检查清单
  • 三级冻结节点已定义并写入项目计划
  • ECN/ECR 表单、审批权限、切换流程已建立
  • 文件版本规则与唯一发布平台运行
  • 固件/硬件/测试版本对应表维护中
  • 委外方明确 PCN/ECN 书面通知义务并写入合同
  • 现场文件稽查机制（防止旧版图纸流转）

12.1 认证地图（按目标市场）

市场常见强制/常规认证
中国大陆CCC（目录内）、SRRC（无线）、CTA（入网）、能效标识
欧盟CE（EMC/LVD/RED 等）、RoHS、REACH、WEEE、电池法规

认证的三个时间陷阱
  1. 以为认证是最后一环：整改需要改板改结构，至少预留一次失败的余量；
  2. 认证样机与量产不一致：用特制样机送测，量产后被抽检不合格，属重大合规风险；
  3. 变更未重新评估：换料、换供应商后认证失效，需重新评估或补测。

12.2 环保与化学物质合规

  • RoHS（有害物质限制）、REACH（高关注物质）、卤素、PFAS（部分地区已限制）；
  • 要求供应商提供材质宣告表与第三方检测报告，并做批次抽检；
  • 电池、包装、回收标识按目标市场要求标注。

12.3 知识产权的四类布局

类型保护什么时点
发明新结构、新算法、新控制方法技术交底尽早，公开前申请
实用新型结构改进、连接关系量产前，授权快
外观设计造型、图案、色彩组合公开/参展/上市前必须申请
软件著作/商标固件代码、品牌名与 Logo版本定稿 / 品牌确定时
最容易漏的：外观专利要在公开前申请

很多团队产品都发布众筹了才想起申请外观专利，此时已构成"现有设计"，可能被无效或无法维权。规则：外观专利必须在任何公开行为（发布会、众筹、电商上架、展会）之前申请。

12.4 商业秘密与人员流动

  • 核心工艺参数、供应商价格、算法细节按商业秘密管理：签署保密与竞业协议、权限分级、文档水印与访问日志；
  • 与委外方签 NDA 时明确：本项目数据不得用于其他客户；
  • 核心固件与算法尽量自控源码，避免全部依赖外部。

第 12 章出门检查清单
  • 目标市场认证清单、责任方、时间表已确定
  • 认证样机与量产一致性已确认
  • RoHS/REACH 等材质宣告与检测报告齐备
  • 外观专利已在公开前提交；发明/实用新型按计划布局
  • FTO 检索已完成，高风险项已规避或取得授权
  • NDA、竞业、源码与数据归属条款已签署

13成本工程与降本

13.1 硬件成本的完整结构

只盯 BOM 是初学者的做法。整机落地成本至少包含：

成本项说明
BOM 物料成本元器件、结构件、包材、线材
NRE 一次性开发费设计、开模、治具、认证、软件
制造成本加工费、工时、能耗、厂内损耗
质量成本不良报废、返修、售后维修、召回
物流与仓储运输、关税、仓储、呆滞库存
一个常被忽略的模型

模具摊销 = 模具总费 ÷ 预计总产量。若预计产量从 10 万降到 2 万，单件摊销成本涨 5 倍。销量预测错误会直接摧毁毛利，因此开模前必须把穴数与产量假设、以及"卖不动"的最坏情况算一遍。

13.2 目标成本设计（Target Costing）

  1. 由售价倒推：目标成本 = 售价 ×(1 − 目标毛利率) − 渠道/物流/售后成本；
  2. 拆解到子系统：主控、显示、电池、结构、包材各分多少；
  3. 设计阶段持续对照，超支即触发降本评审；
  4. 降本优先级：先设计优化（不伤体验），后议价，最后才是换料（风险最高）。

13.3 降本的四条路径与风险

路径收益风险
器件替代（国产/pin-to-pin）见效快需重测性能/可靠性/兼容性
结构减件与工艺简化持续有效需重验证强度与装配
规模议价与集中料号稳定依赖销量，降低灵活性
良率提升纯利润需工艺投入，周期长
降本的底线

涉及安全、认证、可靠性的器件（电池、电源、绝缘件、结构承重件）不允许"悄悄换料"。任何降本必须走 ECN + 重验证 + 留痕，否则省下的成本会以致命的售后成本还回去。

13.4 本章检查清单

第 13 章出门检查清单
  • 目标成本已分解到子系统并纳入设计约束
  • 模具摊销模型与销量敏感性分析已完成
  • 降本方案已评估，涉及安全/认证的变更已走 ECN 并重测
  • 实际 BOM 与量产后成本已复盘，偏差原因明确
  • 质量成本（返修率/售后）已计入，未靠降质换低价

14市场反馈与问题闭环（FRACAS）

14.1 反馈的六个入口

  • 售后返修（RMA）：最有价值的数据，故障件要回收做根因分析；
  • 产线不良：直通率、不良 Pareto、返修记录；
  • 来料异常：IQC 检出批次问题；
  • 客户现场故障：B2B 项目的现场日志与工况；
  • 电商评价与客服工单：隐性期望与体验痛点；
  • 认证/抽检：外部合规风险。

14.2 FRACAS：故障报告、分析与纠正措施系统

  1. 报告：统一表单，记录现象、SN、批次、环境、使用时长；
  2. 分析：故障件做 FA（失效分析），必要时解剖、切片、X-Ray、电镜；
  3. 纠正：临时（筛选/召回/软件补丁）+ 永久（设计/工艺/供应链）；
  4. 闭环：更新 DFMEA/PFMEA、设计规范、测试规范；
  5. 统计：按故障模式统计 MTBF、早期失效率（浴盆曲线的早期段）。
最值得投入的一件事：故障件回收

很多团队只换不修、只修不分析，等于白扔掉最贵的数据。哪怕每月只深度分析 10 台故障件，一年就能沉淀出一本真实的失效模式手册，这是竞品抄不走的东西。

14.3 从问题到设计准则

每一类问题都要沉淀为一条可执行的规则，写进下一代设计规范：

问题沉淀为
某处壳体开裂壁厚与 R 角设计规范、加强筋规则
某芯片交期 20 周禁用料清单 + 双源策略
某接口进水失效密封设计标准与测试加严项
装配工位易错装防呆设计规范（不对称定位）

14.4 迭代决策：什么时候改，什么时候忍

  • 立即改：安全、合规、批量性功能失效；
  • 版本内改：影响体验与口碑，且改动可控；
  • 下代改：需要改模/改板的大改动，且当前影响可控；
  • 用软件补丁：硬件不动的前提下用固件规避（注意记录技术债）。

14.5 本章检查清单

第 14 章出门检查清单
  • 六个反馈入口数据统一汇总，有看板
  • FRACAS 运行，故障件回收与 FA 机制建立
  • 重大异常 8D 闭环，FMEA 已更新
  • 问题库 → 设计准则库沉淀完成（可被二代直接引用）
  • 迭代决策分级机制与二代立项书完成

15从模仿到创新：三段跃迁

15.1 三个阶段的能力与风险

阶段做什么产出主要风险
① 对标仿学拆竞品、跟参数、学原理、补工程能力能做出可用的产品，建立测试与工艺基础侵权、无差异化、价格战
② 局部改良改结构/工艺/材料/交互，解决竞品缺陷自有图纸、自有测试数据、成本或体验优势改良点不够痛，用户不买单
③ 正向创新基于自有设计准则做新架构、新模块发明专利、技术护城河、定义新品类投入大、周期长、市场教育成本

15.2 第一阶段：把"抄"变成"学"

仿学的正确姿势
  • 拆的是原理与失效模式，不是外观曲线；
  • 输出竞品缺陷清单，它就是你的产品定义起点；
  • 同步做专利检索，每条差异化点都查一遍 FTO；
  • 工程能力优先于造型：先把可靠性、良率、供应链跑通，比多好看更重要。

15.3 第二阶段：找到那一个"真痛点"

改良要打在用户真正抱怨的地方，而不是工程师觉得酷的地方。验证方法：

  • 差评与售后数据里高频出现的故障；
  • 维修店/渠道商口中"修得最多"的部位；
  • 竞品规格书里"含糊带过"的参数（往往是短板）。

把改良点量化成一句可验证的承诺，例如"装配螺丝从 14 颗减到 3 颗，拆修时间从 12 分钟降到 3 分钟"。

15.4 第三阶段：正向创新与 IP 护城河

  • 技术模块库：电源、无线、传感、结构卡扣、测试工装、认证文档，逐步标准化复用；
  • 架构创新：不只改零件，而是重构系统（如把分立式改为模块化、把机械结构改为电控）；
  • 专利布局：围绕核心技术申请发明，外围申请实用新型，外观同步保护，形成组合而非单点；
  • 标准与生态：参与行业标准、开放接口协议、做开发者生态——这是最难被模仿的护城河。

15.5 从模仿到创新最容易卡住的地方

三个真实卡点
  1. 一直停留在代工思维：所有技术都在 ODM 手里，自己只会提需求。破解：每个项目强制回收源码、图纸、测试原始数据与模具权属。
  2. 数据没有沉淀：每代产品重踩同样的坑。破解：强制写设计准则库，并在立项时要求引用上一代的问题清单。
  3. 只做微改良不敢投：永远小改，最终被有技术积累的对手碾压。破解：拿出固定比例资源（如 10%–20%）做前瞻预研，与产品线解耦。

15.6 本章检查清单

第 15 章出门检查清单
  • 明确当前产品处于哪一段，并有下一阶段的跃迁计划
  • 竞品缺陷清单 → 改良点 → 量化承诺 已闭环
  • 每个委外项目完成知识回收（源码/图纸/数据/模具）
  • 专利组合布局（发明 + 实用新型 + 外观）已规划
  • 前瞻预研资源与产品线解耦，独立预算

16组织协同与阶段门评审（Stage-Gate）

16.1 阶段门：G0–G5

门决策核心交付物
G0 立项做不做PRD、竞品对标、FTO、成本区间
G1 概念方案定不定ID 方案、堆叠、DFM 预评

16.3 会议节奏

  • 每日站会（爬坡/中试期）：15 分钟，讲昨日产出、今日计划、卡点；
  • 每周项目会：进度、风险、问题单分级（P0/P1/P2）与责任人；
  • 阶段门评审会：只评审交付物与风险，不做技术细节讨论；
  • 异常升级会：P0 问题 24 小时内升级到决策层。

16.4 文档体系：项目的唯一真相源

建议的最小文档集

  • 3D/2D 图纸、Gerber、BOM、原理图
  • DFM/DFMEA/PFMEA、测试计划与报告
  • SOP、检验规范、包装规范、工艺参数表
  • ECN 记录、签样记录、8D 报告、问题库

规则：唯一平台、版本受控、旧版作废可查。微信群里的图纸不算数。

16.5 常见组织病理

四个高频病
  • 研发与工厂互相甩锅：用签样与文件包划分责任边界，谁不按文件做谁担责；
  • 销售承诺先于技术确认：新品未经 G4 不得对外承诺交期与性能；
  • 老板一句话改需求：任何需求变更走 ECR 并评估工期与成本；
  • 项目只有一个"能人"：关键岗位必须有备份，文档必须能让新人接手。

C. 全书一句话口诀

记住这 8 句
  1. 样机证明能做，量产证明能重复做。
  2. 委外不是甩活，是拆清设计、制造、验收三件事。
  3. 逆向学原理，不抄外观；外观专利在公开前申请。
  4. 设计冻结前改图最便宜，开模后改图最贵。
  5. EMC 早摸底，晚测要改板。
  6. 关键料必有双源，长交期料必提前下单。
  7. 任何变更走 ECN，禁止口头与微信改需求。
  8. 故障件必须回收分析，问题库沉淀成设计准则。

D. 一条建议的落地路线（针对第一次做硬件的团队）

  1. 先选一个结构相对简单、量不大的产品跑完整流程，把体系跑通；
  2. 委外 ID 与模具，但自研关键电子与固件，核心自控；
  3. 第一代目标不是赚大钱，是建立供应链、测试能力与问题库；
  4. 第二代开始做局部改良，第三代做架构创新；
  5. 每一步都留痕：图纸、BOM、测试报告、ECN、8D。
