法律要求
  • 署名：注明 UCDP 与数据集版本（v26.1），并保留指向官方下载页或 CC BY 4.0 条款的链接。
  • 标明修改：本项目做了抽样、字段裁剪、类型映射与译名生成，再分发时必须说明「已修改」，不能让人误以为是 UCDP 原始发布。
  • 不得暗示背书：不能声称乌普萨拉大学或 UCDP 认可、认证了本项目。
  • 不附加额外限制：不能对下游施加比 CC BY 4.0 更严格的条款。
本项目加工
  • 固定抽样：只保留事件 id % 50 == 0 的记录，417,968 → 8,405（约 2.0%）。这是规则抽样而非随机抽样，年份与地区分布可能带系统性偏差，不能用于统计推断。
  • 字段保留：开始/结束日期、经纬度、暴力类型、best/low/high 死亡估计、地点名、国家、交战方、conflict_name、来源标题、where_prec 精度等级。
  • 类型映射：type_of_violence = 3（单边暴力）显示为「单边暴力」；国家间与非国家冲突（1、2）统一归入「会战 / 战斗」。因此「围城」全部来自历史数据，不来自 UCDP。
  • 置信度派生：按 where_prec 分级——1–2 为高、3–4 为中、5–6 为低。这是本项目对位置精度的映射，不是 UCDP 自带的「可信度」字段。
  • 地区派生：按经纬度落入五个矩形区域（中东、非洲、欧洲、美洲、亚太），都不命中则记为「跨区域」。
  • 未做：不做死亡人数外推、不补全缺失伤亡、不合并重复事件、不改变原始坐标。
再分发注意
必须同时保留 UCDP 署名、v26.1 版本号、CC BY 4.0 链接，并明确写出「按事件 ID 模 50 抽样、非全量」。任何图表若基于本页样本，应标注样本量（8,405），不得表述为「1989 年以来全球冲突总数」。

  • 相同方式共享：若再分发的是对条目的改编（摘编、结构化改写、合并进新数据库），改编部分须以相同许可（CC BY-SA）发布，不能改为「保留所有权利」。
  • 标明修改：本项目只保留名称、日期、坐标与类型，未复制条目正文；这仍属于「修改/摘编」，须注明。
  • 保留许可与免责声明：不得移除来源页的许可声明，也不得暗示维基百科编者认可本项目。
本项目加工
  • 去重：同一资源 URI 只保留一次，得到 7,409 条唯一候选。
  • 完整性筛选：无坐标、坐标越界（纬度 ±90 / 经度 ±180）、日期无法解析或落在公元前 3000 年–1988 年之外的条目剔除。
  • 占位坐标剔除：部分「中国内战 Campaign」条目在源数据里使用北京通用坐标（39.9167, 116.3833），无法定位，已识别并跳过。
  • 类型派生：按标题关键词判定——siege / fall of / capture of / sack of → 围城；massacre / pogrom → 单边暴力；battle → 会战；其余战役级标题 → 战役线。无法判定的条目直接排除。
  • 去重（与考据条目）：若同名事件已由考据条目覆盖，则不再重复收录，避免同一事件出现两条记录。
  • 中文名生成：DBpedia 中文标签 1,108 条；地名译名库 156 条；规则音译 3,987 条（机械转写，不保证是通行译名）；中英混排 89 条；直接沿用英文原名 87 条。每条在 tz 字段标注来源。
  • 年份与置信度：ISO 风格日期截取为整数年（公元前为负数）；公元 1000 年及以后记为「中置信度」，更早记为「低置信度」。这是保守的可核验性分级，不是对史实真伪的判断。
  • 未做：不抓取条目正文或摘要（所以历史事件详情不补写背景），不做测绘级坐标校正，不逐条人工复核。
再分发注意
坐标是条目坐标（多为现代地名位置），不是古战场测绘点，再分发时不要标为「精确位置」。若把本项目的结构化历史表单独发布，需评估 CC BY-SA 的相同方式共享义务；商业使用本身不被禁止，但署名与共享义务仍然适用。

如何自行核验

  • 打开 data/world_data.js，查看 ATLAS_DATA.meta：version、generatedAt、ucdp、dbpedia、curated、localization 均可直接对照本页数字。
  • 任意点开一条事件，详情中的 src 字段给出 DBpedia 资源页与 Wikipedia 条目的原始链接。
  • 构建逻辑可复核：_raw/ucdp_extract.ps1（抽样）、_raw/build_v2.js（DBpedia 筛选与字段派生）、_raw/build_world_data.ps1（汇总与统计）。
  • 贴图可用第 6 节的 MD5 与 three.js 官方仓库同名文件比对。
