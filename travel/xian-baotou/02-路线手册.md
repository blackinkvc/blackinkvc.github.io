# 🏍️ 西安 → 包头 摩旅路线手册

> **全程 ≈1180 km · 推荐 5 天 4 晚 · 最佳季节 5–6 月 / 9–10 月**
> 路线骨架：G70 → G65 包茂高速 → G20 → S22 / S31
> 证件：身份证 + D 证（摩托） + 行驶证 + 交强险

## 🗓️ 二、每日行程（5 天 4 晚版）

### Day 1｜西安 → 咸阳 → 铜川｜140 km / 3 h 🟢 暖身段

**路线**：西安市 → 河堤路/福银高速入口 → 三原（午餐）→ 铜川新区

**避坑要点**：
- 西安/咸阳市区有**摩托限行段**（早 7–9、晚 5–8），走河堤路或北三环绕城进 G70 入口
- 三原县下 G65 高速转 S107/S208 到铜川（绕开耀州区限行）

**午餐推荐**：三原泡泡油糕、疙瘩面、笼笼肉夹馍（三原小吃天下闻名）

**可选折返**：乾陵（唐高宗 + 武则天合葬墓，三原北约 30 km）— 想看需 + 半日

**夜宿**：铜川新区 / 耀州区（连锁酒店 ~150 元）

> 💡 **今日重点**：暖身段，不赶路。**重点适应装备、路线节奏、机油温度**。

---

### Day 2｜铜川 → 延安｜200 km / 3 h

**路线**：铜川 → G65 包茂高速 → 洛川/黄陵 → 延安

**路况**：G65 全程高速，路况极好，**全程最轻松的一天**

**途经亮点**：
- **黄帝陵**（黄陵县出口 5 km）：古柏 + 沮河景观；05:30 出发可 + 半日
- **洛川会议旧址**：高速沿线，免门票快速参观

**延安必看**：
- 宝塔山（标志性）/ 杨家岭 / 枣园 / 革命纪念馆
- 美食：荞面饸饹、羊肉面、子长煎饼

**夜宿**：延安市区（~180 元，**避开枣园片区选市中心**）

---

### Day 3｜延安 → 靖边波浪谷 → 榆林｜420 km / 5.5 h ⚠️ 最长段

**路线**：延安 → G65 包茂高速 → 靖边下 → 波浪谷（60 km 折返）→ 靖边上 G20 → 榆林

**关键提醒**：
- 今日为全线最长，**早 7:00 出发**
- 靖边下高速后 22 km 龙洲乡，摩托可驶入景区外围

**靖边波浪谷**（龙洲丹霞地貌）：
- 中国版"波浪谷"，丹霞纹路令人震撼
- 摄影最佳时段：**下午 2–4 点**光线斜射呈红色纹路
- 游览 1.5–2 h，务必下午 3 点前离开

**榆林必看**：
- 红石峡（夕阳时最美）/ 镇北台 / **榆林古城骑楼夜景**
- 美食：榆林豆腐、剁荞面、羊杂碎

**夜宿**：榆林古城周边（~200 元）

---

### Day 4｜榆林 → 鄂尔多斯｜280 km / 4 h

**路线**：榆林 → G20 → 蒙陕界收费站（出陕入蒙）→ 鄂尔多斯（康巴什）

**跨省提醒**：
- 出陕入蒙**限速从 100 升到 120**，区间测速密集
- 蒙段**横风强**，双手不离把，过路牌与货车时格外注意
- 景观切换：毛乌素沙地 → 丘陵草原，视野突然开阔

**午后抵鄂尔多斯**，直奔 **成吉思汗陵**：
- 康巴什东南 40 km（甘德利草原）
- 八白室 + 蒙古族建筑群，1.5 h 足够

**夜宿**：康巴什区（新区）
- 晚上 8 点出来看亚洲最大**音乐喷泉广场**（灯光秀）
- 标间 ~250 元，5 星反而常 300 出头

---

### Day 5｜鄂尔多斯 → 响沙湾 → 包头｜150 km / 3 h 🎉 收尾

**路线**：康巴什 → G65 北上 → 响沙湾 → 包头

**上午**：直奔响沙湾（康巴什北上 110 km）
- 中国三大响沙之一，沙子会"唱歌"
- 推荐：骑骆驼、滑沙、沙漠越野车（套票 ~300 元含项目）
- 摩托可直达景区停车场

**下午**：1 点出发包头，G65 北上 1.5 h 抵终点

**庆功**：包头昆都仑区夜市 / 阿尔丁广场周边烤全羊

## 🧰 四、装备清单

### 📂 文件
- 身份证 + 驾照（**D 本**才能上高速）/ 行驶证 / 交强险贴
- **D 证 / E 证**：摩旅必须 D；E 证只能市区骑
- 建议打印一份副本（防雨淋模糊）

### 🧥 服装（昼夜温差 10–18°C）
- **全盔**（半盔高速横风危险）
- 拉力服 / 夏季骑行服 + 抓绒内胆（高海拔段早晚冷）
- 防风骑行手套（秋冬款）+ 防滑骑行靴（过脚踝）
- **分体雨衣**（陕北阵雨说来就来）
- 颈巾 + 速干内层（多带一套）

### 🛠️ 摩托保养（出发前必做）
- 机油 + 链条润滑 + 刹车片检查
- 胎压略加（长途 +0.1 bar）
- 必备：**电动打气筒**（小米米家款）+ 补胎工具 + 备用火花塞 + 备用保险丝

### ⛽ 加油策略
- 油表 1/3 即找站（G65 全程中石化 / 中石油充足）
- 内蒙段备 **200 元现金**（偏远站扫码偶有失灵）

## ⚠️ 六、安全提醒（必读）

1. **西安/咸阳市区限行**：走河堤路或北三环绕开限行段，G70/G65 入口尽量选绕城段
2. **陕西段限速**：G65 高速区间测速密集，**小车 100、货车 80**，超速极易中招
3. **内蒙古段限速**：区间测速同样密集，**120 严控**
4. **横风**：鄂尔多斯/包头段草原开阔带横风剧烈，过卡车时尤其警惕
5. **通讯**：靖边波浪谷段 4G 偏弱、草原段偶有失联，**高德/百度地图离线包务必提前下**
6. **加油现金**：内蒙段建议备用 200 元现金 + 1 张银联标志信用卡
7. **防晒**：陕北、内蒙紫外线比西安强 1–2 个档位，防晒霜 + 长袖手套必备
8. **异地加油**：内蒙部分偏远站可能要求"先付后加"，备好零钱
